Objective

The objective of this assignment is to help you gain practical experience with HTML and CSS by creating a simple webpage. This project will reinforce your understanding of fundamental web development concepts, including HTML structure, CSS styling, and the creation of a visually appealing webpage.

Project Description

Create a personal portfolio webpage that provides information about yourself, your interests, and your skills. The webpage should consist of multiple sections and demonstrate your ability to structure content using HTML and style it using CSS.

01 Requirements

1 HTML Structure

  • Use proper HTML structure with <!DOCTYPE>, <html>, <head>, and <body> tags.
  • Include a <title> in the <head> that reflects the content of your webpage.
  • Divide your webpage into sections such as (not limited to):
    About MeEducationSkillsProjectsContactDownload CV

2 Content

  • About Me: a brief introduction about yourself, with a photo.
  • Education: list your education / training achievements.
  • Skills: list your skills or areas of expertise.
  • Projects: descriptions and links to any personal or class projects you've completed (if any).
  • Contact: your contact information.

3 Text Formatting

  • Use appropriate HTML elements like headings (<h1>, <h2>, etc.), paragraphs (<p>), and lists (<ul>, <li>) to structure your content.
  • Format the text using basic HTML formatting tags.

4 Images

  • Include at least one image (e.g., a profile picture) on your webpage.
  • Use the <img> tag with the src attribute to display images.
  • You can use either online image links or upload images from your computer.

5 CSS Styling

  • Create an external CSS file and link it to your HTML document using the <link> tag.
  • Apply styles to your webpage, including font styles, colors, and spacing.
  • Use CSS classes and IDs to target specific elements and apply custom styling.
  • Ensure that your webpage is visually appealing and easy to read.

6 Layout and Positioning

  • Experiment with different CSS properties to control the layout and positioning of elements on your webpage.
  • Use techniques like margins, padding, and floats to control the placement of elements.
New

7 Download CV Section (PDF)

  • Add a "Download CV" section so visitors can download your CV as a PDF file.
  • Prepare your CV, save it as a PDF, and upload it to your project folder on GitHub together with your other files.
  • Link to it with the <a> tag and the download attribute, for example:
<a href="my-cv.pdf" download>Download my CV (PDF)</a>

Tip: File names on GitHub Pages are case-sensitive. My-CV.pdf and my-cv.pdf are different files. Avoid spaces and Turkish characters in file names. After publishing, click the link on your live website to make sure the download works.

!

Using AI tools: you must know every line of your code

You may use AI tools to help you learn, but you are fully responsible for every line of code you submit. You must understand your entire HTML and CSS code and be able to explain it.

  • You may be asked to explain any part of your code, or to change it in front of the instructor.
  • If you cannot explain code you submitted, it will be treated as work that is not your own.
  • Use only the HTML and CSS you have learned, and make sure you understand anything new before you use it.
